# Dàn ý báo cáo (dự kiến 12 trang)

1. Bìa: môn học, đề 2, tên/MSSV/lớp, giảng viên.
2. Mục tiêu, phạm vi CRUD sinh viên/lớp/điểm; yêu cầu triển khai.
3. Môi trường laptop, phiên bản công cụ, sơ đồ kiến trúc.
4. Mã nguồn, Dockerfile, Compose, GitHub và lịch sử commit.
5. Thiết kế CSDL: classes → students → grades, khóa ngoại và ràng buộc.
6. Thực nghiệm CRUD, ảnh màn hình, kết quả kiểm tra dữ liệu.
7. Nginx reverse proxy và HTTPS hoặc security headers (làm ở bước sau).
8. Prometheus/Grafana: container, web, DB và dashboard (bước sau).
9. Loki/Promtail: luồng log, 2–3 truy vấn LogQL, ảnh kết quả (bước sau).
10. Hardening: từng biện pháp, cấu hình và minh chứng quyền/network/non-root.
11. Kiểm thử restart, lỗi dữ liệu, tình huống sự cố và cách khôi phục.
12. Kết quả, hạn chế, hướng phát triển và tài liệu tham khảo.

Ghi chú mỗi hình: số hình, thao tác, kết quả quan sát. Chỉ dùng ảnh tự chụp từ
hệ thống thật, che mật khẩu/token. Bổ sung mục lục và số trang khi soạn báo cáo cuối.
